# 拾留 PomeKeep

Windows 本地资料收集与找回工具，提供剪贴板历史、截图标注、录屏、轻量笔记、OCR 与关键词搜索。

本仓库用于发布安装包、更新包和接收反馈，应用源代码未在此仓库公开。

## 下载

请前往 [Releases](https://github.com/wmousew/PomeKeep-Releases/releases)。正式版本以已发布的 Release 为准；发布准备期间可能暂无下载文件。

## 更新

2.3.0 起支持在设置中检测更新。自动检测只提示新版本，点击版本号后才开始下载安装更新。

从 2.2.x 首次升级到新程序布局，请使用安装包，并保留个人数据。日常兼容升级采用替换式更新；特殊升级保留安装包入口。

## 反馈

请通过 [Issues](https://github.com/wmousew/PomeKeep-Releases/issues) 提交问题，注明软件版本、Windows 版本和复现步骤。截图和日志请先确认不包含需要保密的内容。
